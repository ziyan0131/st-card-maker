# 🃏 制卡工具 v4.7.2 - SillyTavern Extension

AI 角色卡一键生成与修改工具。

## 功能总览

### 1. AI 生成
- **一键全部生成**：单次调用同时生成角色卡、世界书、开场白（状态栏为正则本地生成）。
- **单独生成**：可分别单独生成角色卡、世界书、开场白、动态状态栏。
- **模块单独生成**：人物卡模块与世界书板块支持逐个单独生成。

### 2. 人物卡模块
- 内置模块：基本信息、性格、外貌、背景故事、恋爱观、说话风格、喜好与厌恶、技能能力、秘密与阴暗面、人际关系、日常习惯、性相关设定。
- 支持自定义模块、每个模块单独设置字数与额外要求。
- 结果可上下移动、手动添加/删除模块、放大编辑、复制。

### 3. 世界书模块
- 内置板块：世界设定、人物关系、魔法体系、势力阵营、场所地点、重要事件、道具物品、日常场景、世界规则、NPC 档案、NSFW 设定。
- 支持自定义板块、条目数/每条字数、触发类型（关键词/始终激活）、插入位置、深度、顺序等全局规则。
- 结果以图一样式展示：启用/关闭、蓝灯（始终）/绿灯（关键词）、位置、深度、顺序、内容均可编辑，支持单条 AI 修改/重生成。

### 4. 开场白
- 生成数量、默认字数、风格偏好（旁白/独白/场景/对话/悬念 + 自定义风格）。
- 每条可设置单独要求与字数。
- 支持编辑、复制、添加、删除、重生成、单条 AI 修改。

### 5. 动态状态栏 + 正则美化
- 选择状态栏包含字段（日期时间地点、当前动作、内心想法、好感度、手机私聊、群聊、色情想法 + 自定义字段）。
- 本地确定性生成状态栏规则（写入世界书）与可直接导入酒馆的正则美化脚本。
- 支持自定义状态栏格式、好感度判定规则、配色主题。

### 6. AI 修改
- **AI 一键修改**：一次修改角色名、角色卡模块、世界书条目、开场白（及状态栏+正则），生成后先显示**修改前后对比**，点击「确认修改」才写入结果，可放弃修改。
- **支持新增条目**：当修改要求中提到「新增/增加/补充」时，可新增角色卡模块、世界书条目、开场白。
- **单条修改/润色/重生成**：结果中的每一项均支持单独 AI 修改、重生成。
- **导入修改**：导入已有角色卡（JSON/PNG）后，可应用导入或让 AI 按意见修改后填充。

### 7. 主/副 API 与任务分配
- 主 API 与副 API 分别配置地址、Key、模型。
- 每个任务可独立选择使用主 API 或副 API：一键全部生成、角色卡生成、世界书生成、开场白生成、模块单独生成、AI 一键修改、单条修改/润色/重生成。
- 留空可跟随酒馆当前 API；支持 /models 加载模型与连通性测试。

### 8. 参考资料
- 当前角色卡、User 人设（可选择任一已有人设）、角色卡内置世界书（可选条目）。
- 自定义参考文本、上传参考文件（txt/json/md）。
- 选择其他角色卡作为参考。
- 参考资料总开关，可一键重新获取酒馆数据。

### 9. 图片与标签
- 角色图片上传与裁剪（导出 PNG 卡片 / 上传酒馆头像）。
- 标签手动添加或 AI 生成。

### 10. 多人角色卡模式
- 开启后可为多个角色同时生成内容。

### 11. 写卡预设
- 恋爱向、RPG 冒险向、日常向、恐怖悬疑向、科幻向一键预设。

### 12. 导出与酒馆集成
- 导出角色卡 JSON、世界书 JSON、正则 JSON、PNG 角色卡（内嵌数据）。
- 直接在酒馆创建角色、覆盖当前角色（自动上传头像并刷新列表）。

### 13. 创建记录（5 槽位）
- 生成/修改后自动保存；同名角色自动覆盖已有记录。
- 槽位支持手动存入、读取、清空。
- 支持导出单个槽位、导出全部记录、从 JSON 导入记录。
- 通过酒馆 extension_settings 跨设备同步。

### 14. 其他
- AI 助手浮窗（右上角，可切换主/副 API）。
- 界面主题（浅粉白/纯白/淡蓝/淡绿/深夜蓝/深紫）与字体大小调节。
- 生成进度与悬浮提示、可停止生成。
- 窗口可拖拽、缩放、最小化、全屏；关闭后后台继续制卡，不覆盖酒馆界面。
- 系统提示词自定义（内置标准提示词与越狱/无审查提示词）。

## 安装

### 方法一：通过酒馆扩展安装器（推荐）
1. 打开 SillyTavern
2. 点击顶部 **扩展** 按钮（拼图图标）
3. 点击 **安装扩展**
4. 输入仓库地址: `https://github.com/ziyan0131/st-card-maker`
5. 点击安装，重启酒馆

### 方法二：手动安装
将本仓库克隆或解压到:
```
SillyTavern/data/default-user/extensions/third-party/st-card-maker/
```
或（旧版ST）:
```
SillyTavern/public/scripts/extensions/third-party/st-card-maker/
```

## 入口
1. 左下角魔法棒菜单 → 制卡工具(卡片图标)
2. 扩展设置面板 → 制卡工具 → 打开制卡工具
