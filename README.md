# 🃏 制卡工具 v3.0 - SillyTavern Extension

AI 角色卡一键生成工具。

## 功能
- 角色卡/世界书/开场白 AI智能生成
- 图片裁剪上传
- MVU动态状态变量(可选启用)
- 每条结果可单独AI修改/重生成
- AI润色模块 + AI助手(右上角)
- 主API管整体生成，副API管单条修改
- API连接测试
- 导出JSON/PNG，导入酒馆创建角色
- 默认浅粉白主题，可调字体大小
- 不覆盖酒馆界面，可自由调节大小
- 关闭后后台继续制卡

## 安装
解压到 `SillyTavern/public/scripts/extensions/third-party/st-card-maker/`
或从扩展面板输入GitHub仓库地址安装。

## 入口
1. 左下角魔法棒菜单 → 制卡工具(卡片图标)
2. 扩展设置面板 → 制卡工具
