# 🃏 制卡工具 v4.7.3 - SillyTavern Extension

AI 角色卡一键生成与修改工具。

## v4.7.3 修复说明（重要）

### 1. 「一键生成」点了没反应 / 结果区不出文字
- **原因一：API 地址留空时被硬编码成了 `http://localhost:5000/api/v1`。** 旧版把「留空」当成"跟随酒馆API"，但生成请求实际发出了 `localhost:5000/api/v1/chat/completions` 这个并不存在的地址（酒馆并不提供该 OpenAI 兼容端点），所以不管你换哪家 API 都不可能成功。
  **现在**：地址留空 = 真正调用酒馆里已经配好的 API（用酒馆的 `/api/backends/chat-completions/generate`，并自动带上你在酒馆里选的模型与代理设置）；读不到酒馆上下文时还有 `generateRaw` / `generateQuietPrompt` / 父页面代答三条兜底通道。
- **原因二：流式(SSE)解析丢字。** 旧代码对每个网络分片直接 `split('\n')`，一条被切到两个分片的 JSON 会被静默丢弃；服务端若忽略 `stream:true` 直接返回整包 JSON，则一个字都取不到，界面还会显示"✅ 完成"。
  **现在**：加入行缓冲（跨分片拼接），并兼容 `data:` 有无空格、`crlf` 换行、整包 JSON、OpenAI/Anthropic/Gemini/旧版 completion 四种返回结构；流式拿不到文本会自动降级为非流式再请求一次。
- **原因三：推理模型（deepseek-reasoner / o1 / R1 等）只返回思维链。** 这类模型会把 `max_tokens` 全部花在 `reasoning_content` 上，`content` 为空，看起来就是"吐不出字"。
  **现在**：会明确提示"模型只返回了思维链，请换普通模型或调大最大输出token"，不再默默显示成功。
- **原因四：出错时提示太隐蔽。** 现在失败信息里会带上接口原始返回片段（前 200 字），方便判断是 401/余额不足/接口不兼容。

### 2. 「主API模型」点加载出不来可选列表
- **原因：浏览器跨域(CORS)拦截 + 触发预检。** 旧代码用 `GET /models` 却带着 `Content-Type: application/json`（非安全列表值，会强制发 OPTIONS 预检），很多中转/本地服务直接拒绝；失败后虽然"交给父页面重试"，但父页面还是同一个浏览器、同一个跨域限制，等于没救，界面上除了一个小 toast 没有任何可见反馈。
  **现在**：
  - 第一优先用不带 `Content-Type`、不带多余的头的请求（能省掉预检）；失败再带完整头重试；
  - 输入框下方新增**状态行**，明确显示"正在请求…/已加载 N 个/失败原因"；
  - 拉不到列表时给出该服务商（OpenAI、DeepSeek、OpenRouter、Kimi、Gemini、GLM、硅基流动、Grok、通义、Mistral、Groq 等）的**常用模型名兜底列表**，可直接点选；
  - 地址留空（跟随酒馆）时，改为先请酒馆服务端去拉该服务商的完整模型列表（服务端请求不受 CORS 限制），拿不到再退回"酒馆当前模型"。
  - 提示：若你的 API 服务商不支持 `/models` 或在浏览器里禁止跨域，直接手动输入模型名即可，不影响生成。

### 3. 「创建记录」槽位显示角色头像
- 现在每个槽位左侧会显示**方形头像缩略图**（保存时自动裁成 96px 的 JPEG 缩略图，体积很小，不会撑爆 localStorage）；**没有上传角色图片的记录不显示头像占位**，只显示文字。
- 旧记录若存过完整图片也会自动显示（优先用缩略图）。

## 功能总览

### 1. AI 生成
- **一键全部生成**：单次调用同时生成角色卡、世界书、开场白（状态栏为正则本地生成）。
- **单独生成**：可分别单独生成角色卡、世界书、开场白、动态状态栏。
- **模块单独生成**：人物卡模块与世界书板块支持逐个单独生成。

### 2. 人物卡模块
- 内置模块：基本信息、性格、外貌、背景故事、恋爱观、说话风格、喜好与厌恶、技能能力、秘密与阴暗面、人际关系、日常习惯、性相关设定。
- 支持自定义模块、每个模块单独设置字数与额外要求。
- 结果可上下移动、手动添加/删除模块、放大编辑、复制。

### 3. 世界书模块
- 内置板块：世界设定、人物关系、魔法体系、势力阵营、场所地点、重要事件、道具物品、日常场景、世界规则、NPC 档案、NSFW 设定。
- 支持自定义板块、条目数/每条字数、触发类型（关键词/始终激活）、插入位置、深度、顺序等全局规则。
- 结果以图一样式展示：启用/关闭、蓝灯（始终）/绿灯（关键词）、位置、深度、顺序、内容均可编辑，支持单条 AI 修改/重生成。

### 4. 开场白
- 生成数量、默认字数、风格偏好（旁白/独白/场景/对话/悬念 + 自定义风格）。
- 每条可设置单独要求与字数。
- 支持编辑、复制、添加、删除、重生成、单条 AI 修改。

### 5. 动态状态栏 + 正则美化
- 选择状态栏包含字段（日期时间地点、当前动作、内心想法、好感度、手机私聊、群聊、色情想法 + 自定义字段）。
- 本地确定性生成状态栏规则（写入世界书）与可直接导入酒馆的正则美化脚本。
- 支持自定义状态栏格式、好感度判定规则、配色主题。

### 6. AI 修改
- **AI 一键修改**：一次修改角色名、角色卡模块、世界书条目、开场白（及状态栏+正则），生成后先显示**修改前后对比**，点击「确认修改」才写入结果，可放弃修改。
- **支持新增条目**：当修改要求中提到「新增/增加/补充」时，可新增角色卡模块、世界书条目、开场白。
- **单条修改/润色/重生成**：结果中的每一项均支持单独 AI 修改、重生成。
- **导入修改**：导入已有角色卡（JSON/PNG）后，可应用导入或让 AI 按意见修改后填充。

### 7. 主/副 API 与任务分配
- 主 API 与副 API 分别配置地址、Key、模型。
- 每个任务可独立选择使用主 API 或副 API：一键全部生成、角色卡生成、世界书生成、开场白生成、模块单独生成、AI 一键修改、单条修改/润色/重生成。
- **API 地址留空 = 直接跟随酒馆里已配置的 API**（使用酒馆当前模型与代理设置，无需再填 Key）；填写地址则为独立的 OpenAI 兼容接口（如 `https://api.deepseek.com/v1`）。
- 模型名可点「📋加载」从 `/models` 拉取；拉不到时会给出该服务商常用模型兜底，也可手动输入。
- 支持连通性测试（「🔌 测试主API」会用一次真实的 chat/completions 请求验证）。

### 8. 参考资料
- 当前角色卡、User 人设（可选择任一已有人设）、角色卡内置世界书（可选条目）。
- 自定义参考文本、上传参考文件（txt/json/md）。
- 选择其他角色卡作为参考。
- 参考资料总开关，可一键重新获取酒馆数据。

### 9. 图片与标签
- 角色图片上传与裁剪（导出 PNG 卡片 / 上传酒馆头像）。
- 标签手动添加或 AI 生成。

### 10. 多人角色卡模式
- 开启后可为多个角色同时生成内容。

### 11. 写卡预设
- 恋爱向、RPG 冒险向、日常向、恐怖悬疑向、科幻向一键预设。

### 12. 导出与酒馆集成
- 导出角色卡 JSON、世界书 JSON、正则 JSON、PNG 角色卡（内嵌数据）。
- 直接在酒馆创建角色、覆盖当前角色（自动上传头像并刷新列表）。

### 13. 创建记录（5 槽位）
- 生成/修改后自动保存；同名角色自动覆盖已有记录。
- 槽位左侧显示角色头像缩略图（无图片则不显示）。
- 槽位支持手动存入、读取、清空。
- 支持导出单个槽位、导出全部记录、从 JSON 导入记录。
- 通过酒馆 extension_settings 跨设备同步。

### 14. 其他
- AI 助手浮窗（右上角，可切换主/副 API）。
- 界面主题（浅粉白/纯白/淡蓝/淡绿/深夜蓝/深紫）与字体大小调节。
- 生成进度与悬浮提示、可停止生成。
- 窗口可拖拽、缩放、最小化、全屏；关闭后后台继续制卡，不覆盖酒馆界面。
- 系统提示词自定义（内置标准提示词与越狱/无审查提示词）。

## 安装

### 方法一：通过酒馆扩展安装器（推荐）
1. 打开 SillyTavern
2. 点击顶部 **扩展** 按钮（拼图图标）
3. 点击 **安装扩展**
4. 输入仓库地址: `https://github.com/ziyan0131/st-card-maker`
5. 点击安装，重启酒馆

### 方法二：手动安装
将本仓库克隆或解压到:
```
SillyTavern/data/default-user/extensions/third-party/st-card-maker/
```
或（旧版ST）:
```
SillyTavern/public/scripts/extensions/third-party/st-card-maker/
```

## 入口
1. 左下角魔法棒菜单 → 制卡工具(卡片图标)
2. 扩展设置面板 → 制卡工具 → 打开制卡工具
