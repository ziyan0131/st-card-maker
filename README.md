# 🃏 制卡工具 v4.0 - SillyTavern Extension

AI 角色卡一键生成工具。

## 功能
- 角色卡/世界书/开场白 AI智能生成
- 图片裁剪上传
- MVU动态状态变量(可选启用)
- 每条结果可单独AI修改/重生成
- AI润色模块 + AI助手(右上角)
- 主API管整体生成，副API管单条修改
- API连接测试
- 导出JSON/PNG，导入酒馆创建角色
- 默认浅粉白主题，可调字体大小
- 不覆盖酒馆界面，可自由调节大小
- 关闭后后台继续制卡

## 安装

### 方法一：通过酒馆扩展安装器（推荐）
1. 打开 SillyTavern
2. 点击顶部 **扩展** 按钮（拼图图标）
3. 点击 **安装扩展**
4. 输入仓库地址: `https://github.com/ziyan0131/st-card-maker`
5. 点击安装，重启酒馆

### 方法二：手动安装
将本仓库克隆或解压到:
```
SillyTavern/data/default-user/extensions/third-party/st-card-maker/
```
或（旧版ST）:
```
SillyTavern/public/scripts/extensions/third-party/st-card-maker/
```

## 入口
1. 左下角魔法棒菜单 → 制卡工具(卡片图标)
2. 扩展设置面板 → 制卡工具 → 打开制卡工具
