# 🃏 SillyTavern 制卡工具扩展 v2.1

AI 角色卡一键生成工具，支持角色卡、世界书、开场白、MVU动态状态栏。

## 功能

- ✨ AI 智能生成角色卡/世界书/开场白
- 🏷️ 自动标签生成（不写"由xx生成"）
- 🔄 每条结果可单独编辑、AI修改、重生成
- 📊 MVU动态状态变量（好感度/HP等状态栏）
- 🖼 图片上传并自由调节大小
- 📋 加载API模型列表
- 🎨 7种主题配色
- 🍺 酒馆深度集成（读取当前角色/世界书）

## 安装

### 方法1：URL安装
1. 扩展面板 → 安装扩展 → 输入仓库地址

### 方法2：手动安装
1. 解压到：`SillyTavern/public/scripts/extensions/third-party/st-card-maker/`
2. 刷新页面

## 入口位置

1. **左下角魔法棒菜单** → 制卡工具
2. **扩展设置面板** → 制卡工具 → 打开

## 文件说明

| 文件 | 说明 |
|------|------|
| manifest.json | 扩展清单 |
| index.js | 入口脚本（注册菜单+弹窗+resize+通信） |
| style.css | 弹窗样式 |
| tool.html | 制卡工具完整界面 |
